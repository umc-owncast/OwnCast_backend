# Owncast
>말을 잘하고 싶은 당신을 위한, 나만의 오디오 OWNCAST

🎙️ ‘언어를 나의 일상 속으로’ 기존의 회화 공부로는 스트레스를 받고, 원하는 목표를 달성하지 못하는 모든 이들을 위해서 만들었어요   
❤️ 해리포터? 야구? 떡볶이 레시피?     

입력된 단어를 통해 자동으로 스크립트를 생성하고 배우고 싶은 언어의 캐스트(오디오)를 제공해요    
MLB의 해설을 이해하고 싶다고요?   
JPOP을 덕질하고 싶다고요?   
혼자 스페인 여행을 떠나고 싶다고요?   
특히 영국 발음을 배우고 싶다고요?   
특정 분야 & 발음을 공부하는 것도   
OWNCAST와 함께라면 다 가능해요   

>[!TIP]
>✔️ OWNCAST 이렇게 사용해요  
관심있거나 좋아하는 키워드를 입력해요   
원하는 스크립트 스타일, 목소리, 오디오 분량을 선택해요   
만들어진 캐스트를 원하는 카테고리 내에 저장해요   
저장한 캐스트를 듣고, 스크립트를 보며 원하는 문장만을 북마크 & 반복해요   
재생목록에서 같은 카테고리 내 캐스트들을 반복해요   
북마크 한 문장들은 ‘학습’ 페이지에서 카드로 공부해요
